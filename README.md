# NFTflip

Telegram-бот для пошуку арбітражу між **Portals**, **Tonnel** та **MRKT**. 
Моніторить пропозиції, порівнює однакові Telegram-подарунки за колекцією + моделлю + номером, 
рахує прибуток з урахуванням комісій і надсилає вигідні сигнали.

## Що вміє
- **Порівняння цін** по трьох майданчиках одночасно
- **Точний збіг** — спочатку за номером подарунка (`#12345`), якщо номер відсутній — за моделлю/бекдропом/символом
- **Калькулятор витрат** — повна вартість покупки з комісією, чистий дохід після продажу, виведення, ROI та маржа
- **Бюджет і ліміти** — ліміт на одну угоду та денний ліміт
- **Фільтр за маржею** — мінімальний поріг сигналу (за замовчуванням 8%)
- **Адаптивний сканер** — не частіше ніж раз на 2 хвилини вдень, до 3 хвилин вночі
- **Без автоматичної покупки** — бот лише шукає й сповіщає

## Швидкий старт (Windows)
1. Скопіюйте цей проєкт на ПК
2. Додайте токен бота в `.env` (скопіюйте `.env.example` → `.env`, заповніть `BOT_TOKEN`)
3. Запустіть `start.bat` — він створить venv, встановить залежності та запустить бота
4. У Telegram відкрийте бота та надішліть `/start`

## Ручний запуск
```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env  # додайте BOT_TOKEN
python run.py
```

## Команди
| Команда | Опис |
| --- | --- |
| `/start` | Головне меню |
| `/search` | Почати пошук: скан ваших підписок, фото подарунка й посилання на купівлю |
| `/add Колекція \| Модель` | Додати підписку на колекцію (або окрему модель) |
| `/watch` | Список підписок |
| `/del <номер\|назва>` | Видалити підписку |
| `/budget <TON>` | Бюджет на одну угоду |
| `/daily <TON>` | Денний ліміт на сигнали |
| `/threshold < % >` | Мінімальна маржа для сигналу |
| `/calc <купівля> <продаж>` | Калькулятор прибутку з урахуванням комісій |
| `/deals` | Останні сигнали |
| `/status` | Стан сканера й підключення майданчиків |
| `/fees` | Поточні комісії |
| `/pause` / `/resume` | Вимкнути/увімкнути сповіщення |
| `/scan` | Ручний скан (тільки для адмінів) |
| `/help` | Довідка |

Кнопка **🚀 Почати пошук** (у меню та на клавіатурі) сканує лише ваші підписки,
фільтрує пропозиції за вашим бюджетом і мінімальною маржею та надсилає картки:
фото подарунка, колекцію з номером, майданчик, де знайдено, і кнопку
**🛒 Купити на <майданчик>** з прямим посиланням на цей лот.

## Комісії (за замовчуванням)
| Майданчик | Купівля | Продаж | Виведення |
| --- | --- | --- | --- |
| Portals | 0% | 2% | 0 TON |
| Tonnel | 0.5% | 0.5% | 0 TON |
| MRKT | 0% | 0% | 0.17 TON |

Налаштуйте точні значення в `.env`.

## Авторизація MRKT
Щоб читати пропозиції MRKT потрібен доступ. Варіанти:
1. `MRKT_TOKEN` — токен із веб-додатку
2. `MRKT_INIT_DATA` — initData з Mini App
3. `TG_API_ID` + `TG_API_HASH` + `python run.py login` — автоновлення через Telethon

## Безпека
- Токен бота зберігається лише в `.env`, `.env` не додається в Git
- Усі дані зберігаються в `data/` (SQLite)
- Бот не виконує купівлі — тільки пошук та сповіщення
